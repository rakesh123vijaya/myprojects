# Cosmetic Product Similarity Analysis Using Ingredient Data

## Project Overview
This project develops a cosmetic recommendation system that suggests skincare products based on ingredient similarity.

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Bokeh

## Features
- Data Cleaning and Preprocessing
- Ingredient Analysis
- One-Hot Encoding
- TF-IDF Vectorization
- Cosine Similarity
- t-SNE Visualization
- Product Recommendation System

## Workflow
Dataset → Data Cleaning → Product Filtering → Ingredient Processing → Similarity Analysis → Recommendation Engine → Visualization

## Results
Products with similar ingredient compositions are grouped together, helping users discover alternative skincare products.
